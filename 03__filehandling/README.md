This module covers file handling in python , including how to create ,read,write and manange files.
It also explores working with different file formats and storing python objects.


TOPICS COVERED :
* Introduction to file handling
* Opening and closing of files
* reading and writing of files
* File modes(r,w,a,rb,wb)
* Using context manager(With)
* working with text and binary files
* file handling with images
* Serialization and Deserialization
* JSON Serialization
* Pickling and unpickling



PRACTICAL WORK:
*Python scripts(.py)
* Google collab notebooks(.ipynb)
* Hands on examples and practice programs



OBJECTIVE:
To understand how python interact with files , handles data storage and converts  python objects into formats
that can be stored and retrieved.
